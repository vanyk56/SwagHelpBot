# SwagHelpBot

Discord-бот: автоматически выдаёт роль «игрок» всем новым участникам сервера (бустеры и боты — исключение), а также система тикетов — приватные обращения игроков к администрации.

## Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `TOKEN` | да | Токен бота из [Discord Developer Portal](https://discord.com/developers/applications) (вкладка Bot → Reset Token) |
| `ROLE_ID` | да | ID роли, которая выдаётся новичкам |
| `BRAND_COLOR` | нет | Фирменный цвет панелей, hex без решётки (по умолчанию `D99A8C`) |
| `SUPPORT_ROLE_ID` | нет | ID роли администрации — она увидит все тикеты. Если не задать, тикеты видят только участники с правом «Администратор» |
| `TICKET_CATEGORY_ID` | нет | ID категории, в которой создавать тикеты |
| `ENABLE_MESSAGE_CONTENT` | нет | `true` = бот читает текст всех сообщений (нужен включённый Message Content Intent в Developer Portal) |

## Подготовка бота (один раз)

1. Discord Developer Portal → ваше приложение → вкладка **Bot** → включите **Server Members Intent** (обязательно) и **Message Content Intent** (если используете `ENABLE_MESSAGE_CONTENT=true`).
2. Пригласите бота через OAuth2 → URL Generator (scope `bot`) с правами: **Manage Roles**, **Manage Channels**, **Manage Messages**, View Channels, Send Messages, Read Message History, Attach Files, Embed Links.
3. В настройках сервера перетащите роль бота **выше** роли «игрок».

## Тикеты

Панель в формате Components V2 (фирменная полоса цвета `BRAND_COLOR` слева, выпадающее меню с причинами обращения). Игрок выбирает причину → создаётся приватный канал (видит только он, администрация и бот) → пишет проблему → администрация отвечает прямо в канале → тикет закрывается кнопкой с удалением канала.

Публикация панели: команда `/setup-tickets` в нужном канале (доступна только администрации, панель закрепляется). Один игрок — один открытый тикет.

Бот отвечает на первое сообщение игрока в тикете без тега и упоминаний. Чтобы бот читал текст **всех** сообщений (например, для будущих автоответов), включите Message Content Intent в Developer Portal и поставьте `ENABLE_MESSAGE_CONTENT=true` — иначе бот получает события сообщений, но текст видит только при теге или ответе.

## Деплой на Railway

1. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → этот репозиторий.
2. Вкладка **Variables** сервиса → добавьте переменные из таблицы выше.
3. **Deploy**. В логах: `Бот запущен как ...`, `Команда /setup-tickets зарегистрирована`.

## Локальный запуск

```bash
npm install
cp .env.example .env   # впишите TOKEN
npm start
```
